Mani — 桌面安装程序

需要 Windows 11 24H2 或更高版本，x64。
启动安装程序后选择安装目录。默认仅为当前用户安装到
LocalAppData/Programs/Mani。如果需要 Program Files 等受保护目录，
请选择“为所有用户安装”，Windows 会请求管理员权限。
首次安装请选择空文件夹。

安装程序按 Windows 显示语言选择中文（简体或繁体），其他语言使用
英文，也可在语言选择窗口手动切换。播放器内已经保存的语言不受影响。

升级使用原安装目录。如需移动已安装的程序，请先卸载，再安装到新目录。
设置、历史记录和续播位置独立保存在 LocalAppData/Mani，卸载会保留它们。
卸载只移除程序安装的文件、快捷方式和关联，不删除目录内自行添加的文件。

可在“打开方式”或 Windows 设置 > 应用 > 默认应用中选择 Mani。
安装程序不会自动替换当前默认播放器。

旧版 MSIX 安装在 Windows 中属于独立应用。如果仍有旧版，请确认新版本
可用后再卸载旧的条目。本安装程序不会自动删除旧包或证书。

安装向导使用 Inno Setup（https://jrsoftware.org/），许可文件随程序
保存在 licenses/Inno-Setup.txt。未签名本地构建仅供验证，不是正式 Beta
下载包。请勿关闭 Windows 安全保护。
